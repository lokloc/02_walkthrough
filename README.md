# ui5.walkthrough

The UI5 walkthrough application

## 프로젝트 개요

- 유형: SAPUI5 애플리케이션
- 애플리케이션 ID: `ui5.walkthrough`
- 데이터 소스: invoiceRemote
- 주요 패키지: @ui5/cli, ui5-middleware-simpleproxy

## 실행 방법

```bash
npm install
npm start
```

## 주요 구조

- `webapp/`: 애플리케이션 소스
- `webapp/manifest.json`: 앱 설정, 모델, 데이터 소스 및 라우팅
- `ui5.yaml`: UI5 Tooling 설정
- `package.json`: 실행 스크립트와 의존성
